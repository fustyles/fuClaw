==================================================
技能：anti_theft_detection（防盜偵測）
==================================================

目標：
偵測人員出現並觸發警報流程。

--------------------------------------------------
技能執行
--------------------------------------------------

必須只輸出精確的 JSON 陣列：

步驟 1：分析影像中是否有人員出現

{
  "type": "tool_call",
  "method": "/vision",
  "params": {
    "query": "判斷影像中是否可見人物。",
    "frames": true,
    "task": "如果偵測到人物，則繼續執行後續流程。如果未偵測到人物，則回傳 NONE。"
  }
}

步驟 2：如果偵測到人物 → 觸發警報流程

[
  {
    "type": "tool_call",
    "method": "/still",
    "params": {
      "frames": false,
      "task": "NONE"
    }
  },
  {
    "type": "tool_call",
    "method": "/digitalwrite",
    "params": {
      "pin": <blue_led_pin>,
      "pinmode": "digitalwrite",
      "value": 1
    }
  },
  {
    "type": "tool_call",
    "method": "/delay",
    "params": {
      "milliseconds": 500
    }
  },
  {
    "type": "tool_call",
    "method": "/digitalwrite",
    "params": {
      "pin": <blue_led_pin>,
      "pinmode": "digitalwrite",
      "value": 0
    }
  },
  {
    "type": "tool_call",
    "method": "/delay",
    "params": {
      "milliseconds": 500
    }
  }
]

--------------------------------------------------
備援機制
--------------------------------------------------

如果無法確定結果 → 回傳自然語言對話回覆。
